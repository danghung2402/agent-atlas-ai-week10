# S02｜Toolformer：分清工具、參數與結果

類型：來源筆記

研究工具使用的學習方式；本作業只借用工具介面觀點。

## 原文的機制

Toolformer 由少量 API 示範產生候選呼叫、執行、按後續文字預測損失篩選，再用保留資料微調模型。模型學習 API 選擇、呼叫時機、參數與結果使用。

## 本主題如何使用

排程工具輸入固定時段、任務需求與事件草稿，回傳具體違規。本作業的 validate 是固定程式；沒有訓練模型學習呼叫 API。

## 不可外推的事

本版評估每個輸入至多一次 API 呼叫，不能把其成績當作多步驟日曆代理的證明。原文的 calendar 工具也不等於一套會修改個人行事曆的服務。

## 來源定位

API 選擇與參數見 PDF p.1 摘要；資料建構與微調見 p.2 §2／Figure 2；評估呼叫限制見 p.6。
