# ReAct：每次動作後看結果

類型：概念整理

觀察不只是過程紀錄，也是下一步決策的輸入。

## 核心機制

ReAct 讓語言推理與動作交錯進行，並用環境回傳的觀察更新下一步。

## 自編例子

目標是整理研究。規劃先讀目錄 → 工具列出檔案 → 觀察發現一份缺頁 → 改為回報缺頁、暫不撰寫該段。工具回傳若被忽略，下一步就可能建立在錯誤假設上。

## 教學簡化

本網站只展示可見的任務狀態與動作理由摘要，不要求任何產品暴露私有內部思考。圖中的循環是概念圖。

## 連到工作流程

本作業將檢查寫成規則，依錯誤種類返回鄰近節點。這是本作業的流程設計，不是宣稱重現 ReAct。
