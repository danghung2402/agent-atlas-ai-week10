五篇研究如何支援 AI 排程教學？

分清機制與評量，避免把不同研究當成排程效能排名。

先區分層次

ReAct 說明行動與觀察；Toolformer 研究工具使用學習；Reflexion 研究文字回饋與記憶。AgentBench 與 WebArena 是評量框架或環境，與前三篇不在同一比較層次。

如何連成一條流程

整理限制 → AI 產生草稿 → 工具回報違規 → 記錄具體修正 → 重跑驗收。這是本 Wiki 依五篇觀點綜合的教學設計，不是任何單篇研究證明的完整排程系統。

訓練與記憶不能混同

ReAct 主要提示設定用凍結模型，但另有微調分析；Toolformer 透過工具資料微調；Reflexion 此機制不更新權重。不能統稱成同一種自我學習。

證據與案例的界線

五篇不是五種排程演算法，也沒有證明本案例最佳。所有時段由作者自編，實際執行證據是固定規則結果與局部修正紀錄。

五份來源的用途與限制

來源／層次機制限制排程教學借鑑
ReAct互動機制在主要提示設定中交錯推理、動作、觀察；另有微調分析可能重複與檢索失敗；不是有 loop 就成功讀取排程檢查結果後再決定修正位置C01, C02, C10, C16
Toolformer工具學習生成、執行、篩選 API 訓練資料，再微調該評估每輸入至多一次 API；不等於多步驟日曆代理明確區分工具名稱、時間參數與回傳狀態C03, C04, C11
Reflexion回饋與記憶Actor、Evaluator、Self-Reflection 角色分工依賴回饋品質，沒有形式成功保證記錄衝突原因與可執行修正，再次檢查C05, C12, C13
AgentBench評量框架跨互動環境觀察多輪決策與結束原因正常結束仍需驗收；不同環境指標不可亂排名分清缺資料、無效草稿、達上限與驗收通過C06, C07, C14
WebArena網站評量環境可部署網站、任務與功能結果檢查特定可重現環境與歷史模型，不代表任意真實網站檢查事件與期限，不以流暢文字當完成證明C08, C09, C15

C01 · S01 · PDF p.3 · §2

ReAct 讓語言推理與動作交錯進行，並用環境回傳的觀察更新下一步。

C04 · S02 · PDF p.2 · §2 / Figure 2

Toolformer 會產生候選 API 呼叫、執行、篩選有幫助的結果，再用保留的資料微調模型。

固定版本 PDF ↗ · 定位詞：finetune

C05 · S03 · PDF p.1 · Abstract

Reflexion 把任務回饋整理成文字反思，存入情節記憶以影響之後的嘗試；此機制不更新模型權重。

固定版本 PDF ↗ · 定位詞：weights

C08 · S05 · PDF p.6 · §3.2

WebArena 依任務類型檢查答案或網站狀態，重點是實際結果是否滿足目標。

固定版本 PDF ↗ · 定位詞：programmatically

C10 · S01 · PDF p.6 · §3 / Error analysis

ReAct 的 HotpotQA 錯誤分析發現重複先前推理與動作、無法跳出循環，以及檢索結果缺乏資訊等失敗模式。

固定版本 PDF ↗ · 定位詞：repetitively

C11 · S02 · PDF p.6 · §4.2 / Decoding setup

Toolformer 本版的該評估設定每個輸入至多一次 API 呼叫；不能把其結果直接當成多步驟行事曆代理的驗證。

固定版本 PDF ↗ · 定位詞：at most one API call

C12 · S03 · PDF p.3 · §3

Reflexion 的模組化描述區分 Actor、Evaluator 與 Self-Reflection：產生行動、評估結果與整理文字反思各有角色。

固定版本 PDF ↗ · 定位詞：three distinct models

C13 · S03 · PDF p.2 · Introduction

Reflexion 依賴自我評估或啟發式回饋的品質，論文指出其沒有成功的形式保證。

固定版本 PDF ↗ · 定位詞：formal guarantee

C14 · S04 · PDF p.4 · §2 / Typical finish reasons

AgentBench 區分格式無效、動作無效、上下文或任務輪數超限等結束原因；正常結束與任務成功仍須分開判斷。

固定版本 PDF ↗ · 定位詞：Invalid Action

C15 · S05 · PDF p.3 · §2

WebArena 用獨立部署的網站環境提高可重現性，避免即時網站變動與驗證碼等因素干擾比較；此設定仍不同於任意真實網站。

固定版本 PDF ↗ · 定位詞：CAPTCHAs

C16 · S01 · PDF p.6 · §3 / Fine-tuning analysis

ReAct 論文除了主要少量示範提示設定，也分析微調實驗；不能把 ReAct 一概定義成永遠不訓練的方法。

固定版本 PDF ↗ · 定位詞：finetuned
