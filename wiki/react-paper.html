S01｜ReAct：依檢查結果修正排程

借用行動後讀觀察的機制，不把一張時間表當作完成證明。

Yao et al. · 書目 2023 · 固定版本 2210.03629v3
原始研究與版本 ↗

原文的機制

ReAct 將語言推理與動作交錯，讓環境觀察成為下一步的輸入。主要提示設定使用凍結模型與少量示範；論文也另有微調分析，不能一概說成永遠不訓練。

本主題如何使用

教學上可把產生草稿、呼叫檢查器、讀取重疊位置與修改草稿分成可見步驟。這是排程教學的綜合設計，不是 ReAct 原始實驗。

失敗與限制

原文 HotpotQA 分析發現重複推理與動作、無法跳出循環及無資訊的檢索結果。有循環仍可能失敗，因此本案例另外設三輪停止規則。

來源定位

互動與主要提示設定見 PDF p.3 §2；重複失敗與微調分析見 p.6。Figure 1 部分擷取文字有編碼雜訊，這裡以可讀正文核對。

證據卡與原文定位

C01 · S01 · PDF p.3 · §2

ReAct 讓語言推理與動作交錯進行，並用環境回傳的觀察更新下一步。

固定版本 PDF ↗ · 定位詞：observation

C02 · S01 · PDF p.3 · §2

ReAct 論文主要設定以少量示範提示凍結的語言模型；不應把這個設定說成每一步都重新訓練。

固定版本 PDF ↗ · 定位詞：frozen

C10 · S01 · PDF p.6 · §3 / Error analysis

ReAct 的 HotpotQA 錯誤分析發現重複先前推理與動作、無法跳出循環，以及檢索結果缺乏資訊等失敗模式。

固定版本 PDF ↗ · 定位詞：repetitively

C16 · S01 · PDF p.6 · §3 / Fine-tuning analysis

ReAct 論文除了主要少量示範提示設定，也分析微調實驗；不能把 ReAct 一概定義成永遠不訓練的方法。

固定版本 PDF ↗ · 定位詞：finetuned
